# MIPLIB data directory

The MIPLIB 2017 instance files are not distributed with this code package.
Download the Collection archive from the official MIPLIB download page:

https://miplib.zib.de/download.html

Extract and, if necessary, decompress the required instances so that their
uncompressed `.mps` files appear directly in this directory. The expected
filenames are stored in `../prob_list.mat`. See `../README.md` for complete
setup and verification instructions.
